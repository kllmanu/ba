# Bachelorarbeit

## Entwicklung einer Webanwendung zur KI-gestützten Erstellung und Überarbeitung von Prüfungsaufgaben für ILIAS

Die Erstellung von Prüfungsaufgaben für Learning-Management-Systeme (LMS) ist häufig mit proprietären, browsergebundenen Editoren verbunden, die keine Versionierung, Wiederverwendbarkeit oder programmatische Generierung von Aufgaben unterstützen. Der Question & Test Interoperability (QTI)-Standard des definiert ein offenes XML-basiertes Austauschformat für Prüfungsfragen und - tests, das von modernen LMS wie ILIAS unterstützt wird.

Während Large Language Models (LLMs) prinzipiell in der Lage sind, erste Aufgabenvorschläge zu generieren, fehlt es an Systemen zur Qualitätsprüfung, Steuerung und Evaluation. Bislang existiert keine ausgereifte Lösung, die den gesamten Prozess – von der intelligenten Aufgabenerstellung über interaktive Nachbearbeitung bis hin zum exportierbaren QTI-Paket für den Import in ILIAS – nahtlos miteinander verbindet.

Ziel dieser Bachelorarbeit ist die Konzeption und prototypische Umsetzung einer Webanwendung. Das System soll Lehrkräften einen strukturierten Workflow zur Seite stellen, der die KI-gestützte Generierung von Prüfungsaufgaben verschiedener Fragetypen, eine iterative menschliche Begutachtung sowie den fehlerfreien Export als valides QTI-Paket für den Import in ILIAS nahtlos bewerkstelligt.
